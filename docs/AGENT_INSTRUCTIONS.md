# Repository agent instructions

This editable file starts from a Mauve.Governance template and is linked from
the managed `AGENTS.md`. It is not manifest-owned: updates never replace it.
Record repository-specific rules for contributors and agents here, such as
required ADRs, test conventions, build commands and local policies. The
[Mauve.Governance Policy](governance.md) still applies and a rule documented
here is not enforced until its own validator or required gate exists.
