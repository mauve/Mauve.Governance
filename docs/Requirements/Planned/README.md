# Planned feature designs

The generic editable starter for this guide is
`src/templates/docs/Requirements/Planned/README.md`. This file is not
manifest-owned and may be adapted to this repository. See the
[canonical Mauve.Governance Policy](../../governance.md) and the parent
[feature lifecycle](../README.md).

Documents here describe proposed behavior, not implemented requirements or
passing test evidence. A design may share a feature number with an active,
partially implemented document, but each individual requirement ID MUST have
only one normative owner. When a requirement gains implementation and
behavioral tests, promote it into `docs/Requirements/` in the same change,
update traceability, metrics/diagnostics, architecture and status, and keep
only remaining proposals here.
